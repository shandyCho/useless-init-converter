## What's new in 0.2.1

A bug-fix release for the s6 boot's sandboxing and shutdown.

- **Sandboxing:** `PrivateNetwork=` now implies `PrivateMounts=` and remounts
  `/sys`, as systemd does. About 30 unit files on Fedora Workstation set it, so
  services such as polkit and accounts-daemon now run in their own mount
  namespace. The hardening comparison shows no setting weaker on s6 for the
  first time.
- **Shutdown:** the display manager now stops along with the sessions. Before,
  each shutdown left six `gnome-session-init-worker` core files. None were left
  in the 3 shutdowns checked, from a session and from the login screen.
- **Initramfs:** the s6 initramfs needs `cryptsetup` only when something is
  encrypted, and `init --boot-only-s6=yes` warns about a root on LVM or MD.

After upgrading, run `sudo uinitconverter init --yes` and reboot.

**Known issues:**
- gnome-shell may still crash at shutdown. It hasn't since the order change in
  0.2.0, in at least 14 shutdowns, which is too few to call it fixed.
- gnome-shell hung for 5 s at one shutdown until it was aborted; cause unknown.
- `s6-ftrigrd` can crash during a reload that adds services, leaving a core file.
  The reload retries and recovers. This is upstream behaviour and isn't fixed here.
