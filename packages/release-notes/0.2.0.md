## 0.2.0의 새로운 점

s6 부팅에서 더 많은 서비스를 systemd처럼 샌드박스 안에서 실행하고, 코어 덤프를
보관하며, zram으로 스왑합니다. 타이머는 일광 절약 시간 변경 전후에 systemd와
똑같이 동작합니다.

- **보안 강화:** rsyslog, earlyoom, udevd, 시스템 버스를 유닛의 샌드박스 안에서
  실행하고, 읽기 전용 마운트를 systemd와 맞췄습니다.
- **선택 항목:** `BUS=`로 dbus-daemon이나 dbus-broker를, `SYSLOG=`로 rsyslog나
  syslog-ng를 고릅니다.
- **코어 덤프:** s6에서도 `/var/lib/systemd/coredump`에 보관합니다.
- **타이머:** DST 변경 전후의 `OnCalendar=`가 `systemd-analyze calendar`와 같아졌습니다.
  DST가 있는 시간대의 타이머는 변경 전후에 0.1.0과 다른 시각에 실행될 수 있습니다.
- **제거:** `AUTO_MASK=`.

업그레이드한 뒤 `sudo uinitconverter init --yes`를 실행하고 재부팅하세요.

**알려진 문제:** gnome-shell이 종료 시 여전히 크래시할 수 있습니다. 종료 순서 수정을
넣었지만 증명되지는 않았습니다. `PrivateUsers=`는 구현되어 있지 않습니다.
